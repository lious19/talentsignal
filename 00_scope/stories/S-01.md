## Story
As the team, we want a React front end, a Node/Express API, and a PostgreSQL database
wired together under Docker Compose so every later story lands on a running system.

## Slice
boot the stack → `StackStarted` → `/health` returns ok for api and db

## Acceptance (Gherkin = demo script + loop stop)

**Stack boots clean**
- **Given** a fresh clone
- **When** `docker compose up` runs
- **Then** the React app, the Express API, and PostgreSQL all start and `/health` is green

**🛡 TRUST — Structured logs at every boundary**
- **Given** the API is running
- **When** any request hits it
- **Then** a JSON log line with a correlation id, route, and duration is emitted to stdout
