# S-05 — Clients and candidates: data model and management
**Agent:** MatchAgent · **Fulfills:** REQ-002 · **Due:** Tue Jul 28
**Basecamp:** https://app.basecamp.com/3945211/buckets/24865175/todos/10116038223

## Story
As a recruiter, I want to manage clients, candidates, and job openings so matchmaking has
real data to work on.

## Slice
`POST /api/candidates` → `CandidateRegistered` → client, candidate, and job-opening records

## Acceptance (Gherkin)
**CRUD across the core entities**
- Given a recruiter
- When they create clients, candidates, and job openings in the React UI
- Then the records persist in PostgreSQL with created/updated timestamps

**🛡 TRUST — PII is flagged at the schema level**
- Given candidate contact data
- When it is stored
- Then PII columns are marked and access is role-gated, honoring the privacy requirement

## Build note (Ali's words)
> Model Clients, Candidates (skills TEXT[], experience, availability), and Job_Openings
> tables; build typed Express CRUD routes and React management screens.

**Vibe-code it:** Boring CRUD, done right. Clean typed contracts here make every AI feature
downstream simpler.

## Why this story matters more than it looks
The PII tagging done here is the foundation for S-15 (privacy/compliance) at R3. Tag PII
in the **first** migration, as TBI rule 7 requires. Retrofitting privacy later is far worse
than doing it now. This is the story where a shortcut becomes a retrofit disaster.

## Open questions / risks
1. **How is PII "flagged at the schema level"?** A column comment? A naming convention? A
   separate metadata table? This is a design decision — needs to be consistent and
   queryable so S-15 can act on it. Log it as a decision.
2. **"Access is role-gated" — but RBAC is S-14.** S-05 needs *some* gating now without
   building all of S-14. Clarify the minimum: probably "recruiter/admin can see PII, others
   can't," enforced with the existing requireAuth plus a role check. Don't build S-14 early.
3. **The role gap from S-02:** there is still no way to create a recruiter account. S-05 is
   a recruiter story. You may need the admin to be able to create recruiters first, or seed
   one. Flag to Ali.
