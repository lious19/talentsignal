## Story
As a sales rep, I want to register and log in securely so only authorized staff reach
agency data.

## Slice
`POST /api/auth/login` → `UserAuthenticated` → a signed JWT and the current user profile

## Acceptance (Gherkin = demo script + loop stop)

**Login issues a token**
- **Given** a registered user
- **When** they POST valid credentials to `/api/auth/login`
- **Then** they receive a short-lived JWT and their role

**🛡 TRUST — Passwords are never stored in the clear**
- **Given** a new registration
- **When** the Node API persists the user to PostgreSQL
- **Then** only a bcrypt hash is stored and the raw password never appears in logs
